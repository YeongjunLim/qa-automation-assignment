쿠폰 적용 기능

TC 설계 · 작성

신규 요구사항 → Generator/Critic 서브에이전트 루프로 초안 생성 중 (v2, 검토 진행 중)
입력된 요구사항
  • 쿠폰은 발급(ISSUED) → 사용가능(AVAILABLE) → 사용완료(USED) 상태를 가진다. 유효기간 경과 시 AVAILABLE → EXPIRED로 전환된다.
  • 이미 USED이거나 EXPIRED인 쿠폰은 다시 사용할 수 없다.
  • 쿠폰마다 최소 주문금액 조건이 있다 (미만이면 적용 불가, 같으면 적용 가능).
  • 존재하지 않는 쿠폰 코드를 입력하면 에러를 반환한다. 한 주문에는 쿠폰을 최대 1개만 적용할 수 있다.
